# abcd-gaussian-optics

Why the ABCD law q' = (Aq + B)/(Cq + D) holds: Gaussian beams are points of the hyperbolic upper
half-plane, and ray-transfer matrices act on them as Möbius maps.

- `scripts/verify_abcd.py`: checks the ABCD law against FFT angular-spectrum propagation
- `scripts/check_gouy_area.py`: checks the Gouy phase as a hyperbolic area
- `scripts/figure_halfplane.py`: the half-plane figure (`figures/`)
- `abcd-law.pdf`: the writeup
